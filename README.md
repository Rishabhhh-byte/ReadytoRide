# Ready-to-Ride Concept Dashboard

A static, browser-based concept dashboard. The original uploaded HTML is preserved as `index.html`; CSS and JavaScript are embedded in that file. The dashboard uses demo data and is not an official Ather Energy product or integration.

## Publish on GitHub Pages

1. Create a new repository on GitHub.
2. Extract this ZIP on your computer.
3. Upload the **contents** of this folder (`index.html`, `.nojekyll`, and `README.md`) to the repository root. Do not upload only the ZIP file.
4. Open **Settings → Pages** in the repository.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/(root)`, then click **Save**.
7. Wait for GitHub Pages to deploy. Your site URL will be shown in Settings → Pages, typically `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Notes

- This is a static demo; edits/submissions are not saved to a server.
- No backend or authentication is included.
- All records and metrics are demo data; proposed assumptions are not confirmed commercial terms.
